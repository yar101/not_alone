# Доработки админки NoAlone

## Высокий приоритет

- [ ] **Баны / блокировки пользователей** — заблокировать нарушителя полностью (причина, срок, разбан). Сейчас есть только кулдаун на квиз.
- [ ] **Просмотр профиля айдола** — карточка с его услугами, ценами, описанием для модерации. Модели `Service`, `ServiceCategory` уже есть.
- [ ] **Модерация услуг** — статус `pending`/`approved`/`rejected` на услуги, очередь на проверку.

## Средний приоритет

- [ ] **Логи административных действий** — кто и когда изменил рейтинг, аннулировал кулдаун, заблокировал пользователя. `IdolRatingLog` уже есть, нужен общий audit trail.
- [ ] **Детальная аналитика на дашборде** — регистрации по дням, топ-5 айдолов по рейтингу, конверсия квиза (сдали / не сдали).
- [ ] **Экспорт данных** — CSV-выгрузка пользователей и заявок.

## Низкий приоритет

- [ ] **Жалобы (Reports)** — пользователи могут жаловаться на любого другого пользователя (и на айдола, и на покупателя). Очередь жалоб для разбора администратором.
