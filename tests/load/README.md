# Нагрузочное тестирование (k6)

В этой папке хранятся скрипты для проверки производительности приложения Not Alone под высокой нагрузкой (стресс-тестирование). Мы используем утилиту [k6](https://k6.io) от Grafana.

## Требования
Все скрипты обёрнуты в Docker. Вам **не нужно** устанавливать k6 локально на компьютер, достаточно запущенного Docker Daemon.

Также рекомендуется запустить мониторинг **Laravel Pulse** перед началом тестов, чтобы отслеживать показатели:
1. Запустите дашборд: `https://[ВАШ_IP]:8443/pulse`
2. Включите сбор метрик сервера (выполните в корне проекта):
   `DEV_HOST=1 docker compose exec app php artisan pulse:check`

## Запуск тестов

### 1. Тест Каталога (Публичный)
Проверяет скорость загрузки списка айдолов (`/search`) без авторизации.
```bash
./run_catalog.sh
```

### 2. Тест Чатов (Требует авторизации)
Проверяет скорость загрузки списка диалогов (`/conversations`). Этот эндпоинт скрыт от гостей, поэтому скрипт попросит вас ввести сессионную куку.

**Как получить куку:**
1. Зайдите на сайт в браузере и авторизуйтесь.
2. Нажмите `F12` (Инструменты разработчика) -> Вкладка **Application** (или Storage).
3. Слева выберите **Cookies** -> ваш сайт.
4. Скопируйте значение (Value) у куки `no_alone_session` или `laravel_session`.
5. Запустите скрипт:
```bash
./run_chat.sh
```
Вставьте скопированное значение и нажмите Enter.

### 3. Глобальный E2E Тест (Песочница)
Самый мощный скрипт, который имитирует полный цикл пользователя: **авторизация -> каталог -> создание заказа -> отправка сообщения в чат**.

**Как это работает:**
Скрипт полностью изолирован. Он делает бэкап вашего `.env`, создаёт временную базу данных `noalone_loadtest`, накатывает туда сидеры, генерирует фейковых ботов для теста и натравливает k6. После завершения теста (даже если вы прервёте его через Ctrl+C) скрипт **автоматически вернёт всё как было** и удалит тестовую базу. Ваша локальная база не засоряется!

**Запуск:**
```bash
./run_master.sh
```

## Что внутри скриптов?
Сценарии лежат в файлах `*_stress.js`. По умолчанию они:
* Плавно разгоняются до **50 одновременных пользователей** за 30 секунд.
* Держат нагрузку 30 секунд (генерируя ~100 запросов в секунду).
* Ожидают, что 95% всех запросов отработают быстрее 1000 мс, а процент ошибок будет < 1%.
